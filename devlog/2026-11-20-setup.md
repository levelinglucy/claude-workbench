## Decisions

- **Fixes go to other repos as PRs from branches, never as pushes to main.** Noe's automation also writes to those repos, so pushing straight to main risks clobbering her work, and Dylan should get the final say on merges.
- **Snapshots go in `imports/`, and work happens on copies in `experiments/`.** That keeps a clean record of what the original code looked like when a bug was found.
- **Continuity is split in two.** `CONTINUITY.md` holds the current state (short, overwritten each session) and `devlog/` holds the history (append-only). A single growing log turns into a wall nobody reads.
